# CMSE 495 Spring 2027 Course Website

This repository contains the source for the CMSE 495 Experiential Learning in
Data Science course website for Spring 2027. It was generated from the
[CMSE course website template](https://github.com/msu-cmse-courses/cmse_course_template)
and uses its calendar-driven schedule workflow to generate the published site.

Visit the course website at
[msu-cmse-courses.github.io/cmse495-SS27](https://msu-cmse-courses.github.io/cmse495-SS27/).
