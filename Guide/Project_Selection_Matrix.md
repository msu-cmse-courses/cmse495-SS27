# Project Selection Matrix

Use this worksheet to organize your thoughts before completing the project preference survey.

## Instructions

1. Start every project at a rating of **3**.
2. Increase or decrease ratings based on evidence.
3. If you need more information, leave the project at a 3 and record your questions.
4. Focus on project fit rather than project quality.
5. There is no "best" project. Different projects support different goals.
